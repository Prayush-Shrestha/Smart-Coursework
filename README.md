# Smart Data Discovery

A coursework project for **CC5067NI – Smart Data Discovery**, focusing on the preparation, exploration, and analysis of data using Python and Jupyter Notebook.

## Overview

This repository contains the practical work and coursework materials developed for the Smart Data Discovery module.

The project currently includes a Jupyter Notebook covering the data preparation process. The notebook documents the steps used to inspect, clean, transform, and prepare data for further analysis.

## Project Structure

```text
Smart-Coursework/
│
├── Data Preparation..ipynb
├── .gitignore
└── README.md
```

## Notebook

### Data Preparation

`Data Preparation..ipynb` contains the data preparation work for the coursework, including the processes required to prepare the dataset for subsequent data analysis and discovery tasks.

The notebook is intended to be executed using **Jupyter Notebook** or **JupyterLab**.

## Technologies Used

* Python
* Jupyter Notebook

* Data Analysis and Data Preparation techniques

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Prayush-Shrestha/Smart-Coursework.git
```

### 2. Navigate to the project

```bash
cd Smart-Coursework
```

### 3. Install Python dependencies

If Python is already installed, install the main data-analysis libraries:

```bash
pip install pandas numpy jupyter
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

Open:

```text
Data Preparation..ipynb
```

and run the notebook cells in order.

## Data Preparation Workflow

The coursework follows a general data preparation workflow:

1. Load the dataset
2. Inspect the data
3. Identify missing or inconsistent values
4. Clean the data
5. Transform data where required
6. Prepare the dataset for further analysis
7. Document the preparation process in Jupyter Notebook
